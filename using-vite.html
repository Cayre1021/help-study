使用 Vite 安装 Tailwind CSS

将 Tailwind CSS 作为 Vite 插件安装是将其与 Laravel、SvelteKit、React Router、Nuxt 和 SolidJS 等框架集成的最无缝方式。

1

创建您的项目

Start by creating a new Vite project if you don't have one set up already. The most common approach is to use Create Vite.

Terminal
npm create vite@latest my-project
        cd my-project
yarn create vite my-project
        cd my-project
pnpm create vite my-project
        cd my-project
bun create vite my-project
        cd my-project
2

安装 Tailwind CSS

通过npm安装tailwindcss和@tailwindcss/vite。

Terminal
npm install tailwindcss @tailwindcss/vite
yarn add tailwindcss @tailwindcss/vite
pnpm add tailwindcss @tailwindcss/vite
bun add tailwindcss @tailwindcss/vite
3

配置Vite插件

将@tailwindcss/vite插件添加到您的Vite配置中。

vite.config.ts
import { defineConfig } from 'vite'

        import tailwindcss from '@tailwindcss/vite'

        export default defineConfig({
          plugins: [

            tailwindcss(),
          ],
        })
4

导入 Tailwind CSS

在导入顺风CSS的CSS文件中添加@ import。

CSS
@import "tailwindcss";
5

开始您的构建过程

使用npm run dev或在package.json文件中配置的任何命令运行构建过程。

Terminal
npm run dev
yarn dev
pnpm dev
bun dev
6

开始在 HTML 中使用 Tailwind

确保已编译的CSS包含在中（您的框架可能会为您处理此问题） ，然后开始使用Tailwind的实用程序类来设置内容的样式。

HTML
<!doctype html>
        <html>
        <head>
          <meta charset="UTF-8">
          <meta name="viewport" content="width=device-width, initial-scale=1.0">

          <link href="/src/style.css" rel="stylesheet">
        </head>
        <body>

          <h1 class="text-3xl font-bold underline">
            Hello world!
          </h1>
        </body>
        </html>
